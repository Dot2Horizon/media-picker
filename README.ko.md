# MediaPicker

**F8을 길게 눌러 재생할 것을 고릅니다.** 멈춰 둔 유튜브 탭이 재생 키를 가로채지 않게 하고, 원하는 미디어를 한 손으로 고르게 해 주는 macOS 메뉴바 앱입니다.

[English](README.md)

## 키

| 키 | 선택 창 닫힘 | 선택 창 열림 |
|---|---|---|
| F8 짧게 | 재생 중인 것 정지 / 마지막 것 재개 | 다음 항목으로 이동 |
| F8 길게 | 선택 창 열기 | 강조된 항목 재생·정지 후 닫기 |
| F7 / F9 | 재생 중인 것의 이전 / 다음 | 강조된 항목의 이전 / 다음 |
| F10 / F11 / F12 | 시스템 음소거 / 볼륨 | 강조된 항목만 음소거 / 볼륨 |

## 조작할 수 있는 것

- Spotify, 음악, TV, VLC
- 크롬·엣지·브레이브·아크 탭 (브라우저 확장 설치 시)
- 사파리 탭 ('Apple Events의 JavaScript 허용' 또는 소스에서 빌드한 사파리 확장)
- 그 밖에 소리를 내는 앱 (시스템 미디어키로)

## 설치

1. [Releases](../../releases)에서 `MediaPicker-x.y.z.dmg`를 받아 응용 프로그램 폴더로 끌어 놓습니다.
2. **처음 실행:** Apple 공증을 받지 않은 빌드라 처음에는 macOS가 막습니다.
   한 번 실행한 뒤 **시스템 설정 › 개인정보 보호 및 보안**에서 **그래도 열기**를 누르세요.
   (또는 터미널에서 `xattr -dr com.apple.quarantine /Applications/MediaPicker.app`)
3. **손쉬운 사용** 권한을 허용합니다. 미디어키를 가로채려면 필요합니다.
   업데이트도 같은 인증서로 서명하므로 한 번만 하면 됩니다.
4. 브라우저 탭: 메뉴바 아이콘 › **브라우저 확장 설치…** 안내를 따릅니다.

macOS 14 이상, Apple Silicon·Intel 모두 지원.

## 소스에서 빌드

```sh
./build.sh --install   # 빌드 후 /Applications에 설치
./release.sh           # dist/에 DMG, zip, 확장 zip, 체크섬 생성
```

사파리 확장은 앱 안에 들어 있지만, Apple Developer ID 없이는 **사파리 › 설정 › 개발자 › 서명되지 않은 확장 프로그램 허용**을
켜야 보입니다(사파리를 끄면 풀립니다).

## 개인정보

모든 처리는 맥 안에서만 이뤄집니다. 브라우저 확장은 `127.0.0.1:17872`의 앱하고만 통신하고,
앱은 브라우저 확장에서 온 연결만 받습니다. 분석·외부 네트워크 요청 없음.
